Migrates the maintained DiLink Android branch from Folia Sonnet 0.6.7 to the complete built-in Folia Major 0.7.20 frontend.

Original project: https://github.com/chthollyphile/folia-major (AGPL-3.0).
Upstream commit: 1b39fd868e2ddda95788f1baa839c032f3e7a285.

Includes Bravais library wall, Lattice playback view, all 14 built-in lyric visualizers and 6 background categories. Retains native Android audio/volume/focus/media controls, BYD split-window declarations, responsive settings and immersive controls. Adds optional playback-session spectrum with an explicit Android permission request.

Uses a persistent release signing certificate for future upgrades. Early R-series debug APKs may require a one-time uninstall because their signing certificates were temporary. Export settings first and expect to log in again if uninstalling.

No external music server is required. Desktop-only Electron mods, wallpaper/export/AI stems, native-path Automix/WebAudio EQ are not Android features. BYD home-card registration, OEM caption transparency and GPU smoothness still need real-car regression; CI evidence is not a replacement for DiLink hardware testing.

This first Major-based release is a prerelease pending vehicle testing. Future upstream releases are monitored weekly and enter a reviewed update workflow before publishing.
