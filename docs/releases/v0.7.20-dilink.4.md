修复分屏启动与窗口内布局细节，沿用原版 Folia Major v0.7.20 的 UI 与全部内置动效。

- 分屏冷启动、回到应用、页面加载和窗口模式切换后，统一启动插件与窗口的隐藏配置，自动恢复透明沉浸式系统栏设置；不再依赖触摸后恢复。原厂窗口标题/拖动条仍由 DiLink 固件控制。
- 分屏切歌提示固定在当前窗口的水平中央、播放进度条上方；短歌名和长歌名位置保持一致，切歌更新和自动消失保留。
- 专辑墙二级菜单分别适配全屏和分屏：全屏保留460px宽度，分屏使用360px紧凑布局，保留至少48px主要触控目标及窄窗滚动。
- 使用真实 Android 多窗口状态判断布局，不把窄的全屏窗口误判成分屏。

固定发布签名和应用标识保持一致，可从 0.7.20-dilink.3 覆盖升级。没有更换原生播放、系统音量、方向盘控制、账号存储或音乐平台协议。

已知边界：BYD 原厂首页音乐卡片仍未完成适配；汽水音乐尚未接入，详情见 [可行性记录](https://github.com/Leeacc/folia-dilink-android/blob/main/docs/qishui-feasibility.md)。本版新的分屏启动行为仍需实车复测，模拟器不能替代 DiLink 固件验证。
